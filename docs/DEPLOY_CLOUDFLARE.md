# Деплой на Cloudflare Workers (бесплатный план)

Приложение работает на Cloudflare Workers через адаптер OpenNext (`@opennextjs/cloudflare`). Данные и вход остаются в Supabase. Настройки лежат в [wrangler.jsonc](../wrangler.jsonc) и [open-next.config.ts](../open-next.config.ts).

## Как это устроено

- `pnpm cf:build:docker` собирает пакет для Workers в папку `.open-next/`. Сборка идёт в Linux-контейнере Docker: адаптер создаёт символические ссылки, а Windows разрешает их только администратору. Контейнер получает копию исходников **без `.env.local`**, поэтому ни один секрет не попадает в пакет.
- `pnpm cf:deploy` собирает и выкладывает пакет (`wrangler deploy`).
- Публичные настройки (адрес Supabase, публичный ключ, часовой пояс, `APP_URL`) лежат в `wrangler.jsonc`, `vars`. **Секреты** (`SUPABASE_SECRET_KEY`, `CRON_SECRET`) хранятся только в Cloudflare. Их загружает `pnpm cf:secrets` прямо из `.env.local`, ничего не печатая.
- `public/_headers` включает долгое кеширование статики.

## Первый выкат (один раз)

1. Аккаунт на [dash.cloudflare.com](https://dash.cloudflare.com) (бесплатный, карта не нужна).
2. `pnpm wrangler login` — откроется браузер, нажмите «Allow».
3. `pnpm cf:deploy` — Wrangler напечатает адрес вида `https://taptogo.<ваш-аккаунт>.workers.dev`.
4. `pnpm cf:secrets` — загрузит секретные ключи в Cloudflare.
5. Впишите этот адрес в `wrangler.jsonc` → `vars.APP_URL` и выполните `pnpm cf:deploy` ещё раз: от `APP_URL` строятся ссылки на карточках и в письмах.
6. Создайте администратора: `pnpm create-admin вы@почта.kz "Имя"` (работает с той же базой Supabase) и войдите на сайт.

## Следующие выкаты

`pnpm cf:deploy`. Если менялись секреты — ещё `pnpm cf:secrets`.

## Ограничения бесплатного плана

| Что                          | Лимит             | Как мы                                                                                                       |
| ---------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------ |
| Размер кода Worker           | 3 МБ после сжатия | сейчас около 2,6 МБ с минификацией (`"minify": true`); проверка: `pnpm cf:size`                              |
| Процессорное время на запрос | 10 мс             | страницы лёгкие, но тяжёлые операции (выгрузка ZIP с QR на тысячи карточек) могут упираться; следим по логам |
| Запросов в сутки             | 100 000           | для старта достаточно                                                                                        |

Как мы укладываемся в размер: вместо библиотек Excel и ZIP написаны свои небольшие записывающие модули (`src/lib/xlsx.ts`, `src/lib/zip.ts`), графики рисуются только в браузере, прокси не загружает библиотеку проверки данных. Перед каждым выкатом запускайте `pnpm cf:size`: если число `gzip` подходит к 3000 КиБ, что-то разрослось.

## Адрес, который зашивается в карточки

Ссылка на метке — `APP_URL/t/КОД`. Пока адрес не финальный, **не блокируйте NFC-метки на запись**: незаблокированные можно перезаписать. Блокируйте и раздавайте клиентам только когда адрес окончательный (свой домен или `workers.dev`). Домен потом подключается в Cloudflare («Workers → taptogo → Settings → Domains»), и сайт отвечает по обоим адресам.

Для домена `.kz` по правилам регистратора сайт должен размещаться на хостинге в Казахстане и не прятать зарубежный IP за прокси, поэтому с Cloudflare он не сочетается. Используйте домен другой зоны или `workers.dev`.
